# Mystic Hills — редизайн сайта бронирования

Презентация редизайна сайта глэмпинга Mystic Hills с живым демо-прототипом. Статический сайт без сборки — публикуется на GitHub Pages.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Презентация: 17 слайдов «было / стало», прототип встроен прямо в слайды |
| `demo.html` | Демо нового сайта: каталог, фильтры, карточка домика, календарь занятости, бронирование в пять шагов |
| `variants/` | Три направления главной: «Ночной лес» (основное), «Туман», «Арт-объект» |

## Управление презентацией

| Клавиша | Действие |
|---|---|
| `→` `←` `Space` | Листать слайды |
| `D` | Демо-режим: прототип поверх презентации, переключение телефон / планшет / десктоп |
| `O` | Обзор всех слайдов |
| `N` | Заметки докладчика |
| `F` | На весь экран |
| `Esc` | Закрыть демо, обзор или заметки |

Свайп пальцем, перетаскивание мышью или горизонтальный жест по трекпаду тоже листают слайды. Ссылка на конкретный слайд: `index.html#5`.

## Глубокие ссылки демо

Для встраивания экранов в слайды прототип понимает параметры:
`demo.html?view=booking&step=3&house=sfera-kupel&dates=1&extras=1&name=1&no=1`, а также `?view=house|filters|menu`, `?scroll=houses|banya|cafe|contacts`.

## Условности прототипа

Цены, занятость и допуслуги взяты с текущего сайта и условны. Занятость генерируется детерминированно (около 22 % дней), оплата не проводится. Для запуска нужна интеграция с Bnovo (см. последний слайд).

## Локальный запуск

```
python3 -m http.server 8080
```

и открыть `http://localhost:8080/`.
